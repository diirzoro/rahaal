# Rahaal Scraper Extension (v1.0.0)

إضافة كروم لسحب بيانات التذاكر والتأشيرات تلقائياً إلى نظام رحّال ERP.

## طريقة التثبيت (Load unpacked)

1. حمّل ملف `rahal-extension.zip` من داخل رحّال (إعدادات المكتب ← إضافة المتصفح ← تحميل الإضافة).
2. فك الضغط في مجلد ثابت (مثلاً `~/rahal-extension/`).
3. افتح Chrome ← `chrome://extensions/` ← فعّل **Developer mode** أعلى اليمين.
4. اضغط **Load unpacked** واختر المجلد المفكوك.
5. الإضافة ستظهر بأيقونة 🕋. ثبّتها في شريط الأدوات.

## طريقة الربط

1. في رحّال: **إعدادات المكتب ← إضافة المتصفح ← إنشاء رمز جديد** — انسخ الـ Token.
2. افتح الإضافة (الأيقونة) والصق:
   - عنوان الخادم: `https://your-rahaal-domain.example.com`
   - الرمز الشخصي: `rhl_pat_xxxxxxxxx`
3. اضغط **فحص الاتصال والحفظ**.

## طريقة الاستخدام

1. افتح صفحة تذكرة (اليمنية / Fly Aden) أو مستند تأشيرة (KSA e-Visa).
2. اضغط أيقونة الإضافة → **قراءة المستند من الصفحة**.
3. راجع البيانات المستخرجة → **سحب إلى رحّال**.
4. اختر العميل والمورد + طريقة الدفع → **تأكيد الحفظ**.
5. القيد المحاسبي يُنشأ تلقائياً في رحّال ✅.

## البوابات المدعومة (v1.0)

- ✅ Yemenia Airways (parser أولي — يتحسن مع نماذج HTML حقيقية)
- ✅ KSA e-Visa (mofa / enjazit)
- 🔜 Fly Aden, البركة للنقل، الموافقات الأمنية (Ethiopia/Egypt)

## الأمان

- الاتصال مؤمّن عبر **Personal Access Token (PAT)** بصيغة `rhl_pat_...`
- كل مكتب له رموزه الخاصة (Multi-tenant isolation).
- يمكن إبطال أي رمز فوراً من رحّال ← إعدادات المكتب.
- الرمز يُخزّن محلياً في `chrome.storage.local` فقط (لا يُشارك خارج جهازك).

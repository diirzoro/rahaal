# Rahaal Scraper Extension (v1.2.0)

إضافة كروم لسحب بيانات التذاكر والتأشيرات تلقائياً إلى نظام رحّال ERP.

## 🆕 الجديد في v1.2.0
- ✅ **دعم ملفات PDF** — الإضافة الآن تقرأ صفحات معاينة الطباعة وملفات `.pdf` مباشرة عبر مكتبة **pdf.js** المدمجة.
- ✅ عند فتح صفحة PDF، الإضافة تكتشف ذلك تلقائياً وتُظهر زر **📕 قراءة PDF**.
- ✅ الـ 6 Parsers تعمل الآن على النصوص المستخرجة من الـ PDF بنفس دقة الـ HTML.

## طريقة التثبيت (Load unpacked)

1. حمّل ملف `rahal-extension.zip` من داخل رحّال (إعدادات المكتب ← إضافة المتصفح ← تحميل الإضافة).
2. فك الضغط في مجلد ثابت (مثلاً `~/rahal-extension/`).
3. افتح Chrome ← `chrome://extensions/` ← فعّل **Developer mode** أعلى اليمين.
4. اضغط **Load unpacked** واختر المجلد المفكوك.
5. الإضافة ستظهر بأيقونة 🕋. ثبّتها في شريط الأدوات.

## طريقة الاستخدام

### الحالة أ: صفحة HTML عادية
1. افتح صفحة تذكرة (اليمنية / Fly Aden) أو تأشيرة (KSA e-Visa) الخ.
2. اضغط أيقونة الإضافة → **🔍 قراءة الصفحة**.
3. راجع البيانات المستخرجة → **🚀 سحب إلى رحّال**.
4. اختر العميل والمورد + طريقة الدفع → **تأكيد الحفظ**.

### الحالة ب: صفحة PDF (معاينة طباعة، أو ملف .pdf) 🆕
1. افتح صفحة الـ PDF مباشرة في Chrome (سواء `printPdf/...` أو رابط ينتهي بـ `.pdf`).
2. اضغط أيقونة الإضافة → ستكتشف تلقائياً أنها PDF.
3. اضغط **📕 قراءة PDF** — ستُحمّل الإضافة الـ PDF وتستخرج النصوص باستخدام pdf.js.
4. راجع البيانات → **🚀 تأكيد وحفظ في رحّال** (نموذج التأكيد يفتح داخل الـ popup — بدون خروج من صفحة الـ PDF).

## الأمان

- الاتصال مؤمّن عبر **Personal Access Token (PAT)** بصيغة `rhl_pat_...`
- كل مكتب له رموزه الخاصة (Multi-tenant isolation).
- يمكن إبطال أي رمز فوراً من رحّال ← إعدادات المكتب.
- الرمز يُخزّن محلياً في `chrome.storage.local` فقط.
- ملفات الـ PDF تُقرأ محلياً في المتصفح، لا تُرفع لأي خادم خارجي.

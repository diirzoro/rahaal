## خريطة أمان الوظائف المعتمدة (ما لا تمسّه هذه الحزمة)

- **SSO / دخول معراج:** لا يوجد أي سطر في الحزمة يلمس `sso-token`/`sso/verify`/`account-link` أو أي واجهة دخول — سلوك الـ Live يبقى كما هو حرفياً.
- **عارض المستندات/الجوازات:** patch 4 إضافي بحت مع بقاء كل المسارات القديمة (روابط موقّعة، external_url، file_ref، سجلات معراج التاريخية). الواجهة لا تُستبدل (patch 4b مرجع فقط). لا CORS جديد — الـ proxy يجعل الوصول same-origin أصلاً.
- **سياسة الإلغاء/الضمان (Escrow):** لا يوجد أي تعديل على منطق الإلغاء أو الصلاحيات — موقف المكتب يبقى موقفاً، والقرار النهائي للسوبر أدمن حصراً، وسلسلة التدقيق كما هي. (الرفع المتعدد لأدلة الإلغاء يغيّر «طريقة الرفع» فقط، لا الصلاحيات ولا التدفق).
- **تكامل معراج:** الحجوزات الواردة، الجوازات، القبول/الرفض، package_ref، المقاعد، HMAC/webhooks — لا تعديل.

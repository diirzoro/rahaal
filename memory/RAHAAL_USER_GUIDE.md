## 🔐 1) تسجيل الدخول وإنشاء الحساب

### شاشة التسجيل `/signup`
**الحقول الإجبارية:**
| الحقل | الوصف | مثال |
|:---|:---|:---|
| `name` | اسم المكتب التجاري | "مكتب النور للسياحة" |
| `owner_name` | اسم صاحب المكتب | "أحمد علي محمد" |
| `owner_email` | البريد الإلكتروني (يُشترط Gmail) | `ahmad@gmail.com` |
| `owner_phone` | **رقم الهاتف / الواتساب مع رمز الدولة** | `+967771234567` |
| `owner_password` | كلمة سر (6 أحرف فأكثر) | `MyPass2025!` |
| `ref` (اختياري) | رمز إحالة إن وُجد | `UQ7Z98W8` |

**Workflow:**
1. زيارة `https://rahaal.targetmediagrp.com/signup`
2. تعبئة الحقول → التحقق التلقائي من صحة الهاتف
3. الضغط على "ابدأ الآن مجاناً"
4. تحويل تلقائي للـ Dashboard مع 30 قيد تجريبي مجاني + شهر تجربة

## 🎫 3) حجز التذاكر (Tickets)

### الحقول الأساسية:
| الحقل | إلزامي | نوع | ملاحظات |
|:---|:---:|:---|:---|
| التاريخ | ✅ | تاريخ | تاريخ إصدار التذكرة |
| المسافر | ✅ | نص | اسم المسافر كما في الجواز |
| PNR / رقم التذكرة | ⚪ | نص | يُستخدم لكشف التكرار |
| المسار (route) | ⚪ | نص | مثل "SAH-CAI" |
| الشركة الناقلة | ⚪ | نص | Yemenia, Saudia |
| حساب القبض | ✅ | قائمة | **عميل** (بيع آجل) أو **صندوق/بنك** (بيع نقدي) |
| المورد | ✅ | قائمة | من دليل الحسابات |
| العملة | ✅ | قائمة | USD / SAR / YER |
| التكلفة | ✅ | رقم | من المورد |
| سعر البيع | ✅ | رقم | للعميل |
| طريقة الدفع | ✅ | آجل / نقدي | نقدي يتطلب صندوق |

### Workflow الأساسي:
1. الضغط على **"+ سند تذكرة"** أو **"استيراد Excel"**
2. اختيار **المسافر → المسار → PNR** (إن وُجد)
3. تحديد **حساب القبض** (عميل أو صندوق)
4. **قيد محاسبي تلقائي:**
   - آجل: مدين 1301 عميل / دائن 2101 مورد + 4101 عمولة
   - نقدي: مدين 1101/1201 صندوق / دائن 2101 مورد + 4101 عمولة

### ميزات إضافية (v3.9.11+):
- 📅 **فلتر تاريخي سريع:** اليوم / آخر ٧ أيام / هذا الشهر / مخصص
- ☑️ **تحديد جماعي:** Checkbox في كل صف + Select-All
- ✏️ **تعديل جماعي:** تغيير المورد/التاريخ/الدفع لعدة سجلات
- 🗑️ **حذف جماعي:** مع عكس القيود تلقائياً
- 🔍 **بحث متقدم:** بحسب أي حقل

## 💵 7) سند القبض (Receipt Voucher)

**الغرض:** تسجيل استلام مبلغ من عميل.

**الحقول:**
| الحقل | الوصف |
|:---|:---|
| التاريخ | تاريخ الاستلام |
| المستلم منه | عميل من القائمة |
| الصندوق/البنك | الوجهة (صندوق أو بنك) |
| العملة | USD/SAR/YER |
| المبلغ | القيمة المستلمة |
| طريقة الدفع | نقدي / تحويل / شيك |
| البيان | وصف اختياري |

**القيد المحاسبي التلقائي:**
- مدين: الصندوق/البنك (1101 أو 1201)
- دائن: العميل (1301)

## 💱 9) صرافة العملات (FX)

**الغرض:** بيع/شراء عملة مقابل أخرى.

**النوع:**
- 📥 **شراء** (Buy): مثلاً شراء USD مقابل SAR
- 📤 **بيع** (Sell)

**الحقول:** العملة، المبلغ، العملة المقابلة، المبلغ المقابل، صندوق المصدر، صندوق الوجهة، سعر الصرف الفعلي.

**القيد:** تدخل + خروج من صندوقين بعملتين مختلفتين + هامش ربح 4103.

## 👥 10) العملاء والموردون والصناديق

### العملاء (Clients):
- الاسم، الهاتف، البريد
- حساب الأب (Parent Account) — افتراضياً 1301
- الأرصدة الحية بكل عملة

### الموردون (Suppliers):
- نفس الحقول + parent 2101 افتراضياً

### الصناديق والبنوك (Boxes):
- الاسم بالعربية والإنجليزية
- النوع (`cash` صندوق / `bank` بنك)
- العملة الرئيسية
- parent 1101 (صندوق) أو 1201 (بنك)
- **الأرصدة الحية** بكل عملة

## 📊 13) التقارير المالية (Reports)

### تبويبات:
1. **الأرباح (Profits):** بحسب فترة، نوع (تذاكر/تأشيرات/خدمات)
2. **كشف حساب (Statement):** عميل/مورد/صندوق مع الرصيد المتحرك
3. **ميزان المراجعة (Trial Balance):** جميع الحسابات مع أرصدتها
4. **قائمة الدخل (Income Statement):** الإيرادات - المصروفات = صافي الربح
5. **🔒 الإقفال السنوي (v3.9.14):** آلية إقفال السنة المالية

### آلية الإقفال السنوي:
1. اختيار السنة → معاينة (إيرادات، مصروفات، صافي)
2. زر "🔒 تأكيد الإقفال" → قيد إقفال 31/12 يصفّر الإيرادات والمصروفات
3. ترحيل صافي الربح إلى **3900 الأرباح المدوّرة**
4. **قفل السنة:** أي محاولة إضافة قيد بتاريخ السنة المقفلة تُرفض

## 🔗 14) إضافة المتصفح (Chrome Extension) — قارئ رحّال

**الغرض:** استخراج بيانات التذاكر/التأشيرات تلقائياً من مواقع الحجز والـ PDF.

### التنصيب:
1. تنزيل `rahal-extension.zip` من `/rahal-extension.zip`
2. فك الضغط
3. Chrome → chrome://extensions → Developer mode → Load unpacked
4. الضغط على أيقونة رحّال في الشريط
5. لصق **PAT Token** من: رحّال → إعدادات المكتب → إضافة المتصفح

### الاستخدام:
- افتح صفحة تذكرة (يمنيا، سعودية، البركة، رواد الأفضل، ...)
- اضغط "🔍 قراءة الصفحة (HTML)" أو "📕 قراءة PDF"
- راجع البيانات → اضغط "🚀 سحب إلى رحّال"
- اختر العميل والمورد والصندوق → تأكيد

### الحصة المجانية (Trial Quota):
- **30 قراءة مجانية** لكل مكتب Trial
- عند بلوغ الحد → قفل تلقائي + رسالة ترقية
